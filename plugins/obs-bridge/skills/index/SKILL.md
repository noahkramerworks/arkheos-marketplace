# OBS Bridge router

Route only.

- Use [$inspect](../inspect/SKILL.md) for connection diagnosis, version/capability checks, and read-only OBS state.
- Use [$apply](../apply/SKILL.md) for a typed, reversible scene/input plan.
- Use [$rollback](../rollback/SKILL.md) for an existing OBS Bridge receipt.

Read [bridge contract](../../references/bridge-contract.md) for any mutation. Product outcomes such as vertical-stream setup or podcast production belong to a separate product plugin that composes this bridge. The admitted boundary is obs-websocket 5.7.4 / RPC 1; never substitute UI control or raw protocol passthrough.
