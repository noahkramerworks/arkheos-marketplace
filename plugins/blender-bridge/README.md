# Blender Bridge 0.3

Certified native, reversible Blender 5.2.1 DCC control through a typed Blender extension and authenticated coordinator.

Seven focused Skills expose sixteen MCP tools for installation, extension and project lifecycle, bounded inspection, revision-guarded typed transactions, atomic pose-action authoring, owned rendering, viewport capture, GLB/FBX/USD/OBJ/Alembic export, and exact receipt rollback. Animation inspection includes reproducible semantic digests, and GLB animation/material/extras options are explicit. Blender remains authoritative. State lives below `$CODEX_HOME/state/plugins/blender-bridge/v1`.

The free bridge is released under GPL-3.0-or-later for both personal and public ArkheOS marketplaces. Arbitrary Python, raw operator passthrough, arbitrary RNA setters, UI automation, unrestricted filesystem access, and unbounded payloads are rejected. Read `references/api-admission.md` and `design/plugin.md` for the admitted contract.
