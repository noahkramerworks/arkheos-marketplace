# Export through Blender Bridge

Read [render and export](../../references/render-export.md) and [security and recovery](../../references/security-recovery.md). Inspect first and bind exact revision. Require an existing output directory outside the project and an absent final artifact. Select one format and its closed options, then call `export_artifact` once. Report receipt, Blender identity, format, final path, size, and both promotion/final hashes. Do not package, upload, or publish unless a composing product workflow owns that effect.
