# Intent and non-goals

Blender Bridge 0.2.0 recertifies the released seven-Skill, sixteen-tool boundary against Blender 5.2.1 LTS and Bridge Runtime profile, evidence, and certificate v1.2. The official version-bound Blender Python API is the admitted control surface. It supplies typed native scene reads and writes, separate saved-file and process readback, and exact byte rollback. Blender remains authoritative for scene, dependency graph, render, viewport, and export state; the bridge retains enrollment, revisions, checkpoints, receipts, owned jobs and processes, and rollback authority.

No arbitrary Python, raw operator or RNA passthrough, free-form drivers, modal UI automation, screen scraping, unrestricted filesystem access, raw protocol payload, export-only boundary, unbounded payload, product-specific pipeline, cloud service, or shared Bridge Runtime runtime dependency is added.
