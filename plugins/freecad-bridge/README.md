# FreeCAD Bridge

Free, Bridge Runtime-certified control of FreeCAD 1.1.3 through its documented Python API.

Use `freecad-bridge@personal` or `freecad-bridge@arkheos`. The bridge exposes six closed tools for status, setup, inspection, parametric transactions, STEP/STL export, and exact receipt rollback. It never accepts Python, macros, shell commands, raw payloads, or unrestricted paths. Read `design/plugin.md` for the complete package and lifecycle contract.
