# Godot Bridge router

Route only.

- Use [$setup](../setup/SKILL.md) for engine inspection, project enrollment, and editor lifecycle.
- Use [$inspect](../inspect/SKILL.md) for read-only project and runtime state.
- Use [$edit](../edit/SKILL.md) for one typed revision-guarded transaction.
- Use [$playtest](../playtest/SKILL.md) for owned playtest runs and viewport capture.
- Use [$export](../export/SKILL.md) for revision-bound Windows export inspection and artifact building.
- Use [$rollback](../rollback/SKILL.md) for an exact receipt.

Product outcomes and game design belong to a separate product plugin. Read [architecture](../../references/architecture.md) before changing that boundary.
The bridge is usable only while its [API admission](../../references/api-admission.md) remains current.
