# Security and state

The coordinator binds only `127.0.0.1`, uses a new 256-bit bearer token, caps request bodies at 2 MiB, and writes the endpoint/token descriptor beneath bridge-owned state. The extension is copied only into the bridge-owned isolated Krita profile, accepts an exact 5.3.3/PyKrita identity and fixed operation set, and has no evaluator, action/filter passthrough, command, or raw-pixel input. `.kra` paths must resolve inside an enrolled root beneath the current user's real profile; exports resolve only beneath the bridge export directory. Layer ownership requires both an `ArkheOS_` name and color label 8. Extension files, profile, checkpoints, receipts, process records, enrollments, and runtime descriptors have separate state subdirectories. Foreign files, layers, receipts, checkpoints, profiles, and processes stop closed.
