# Architecture

Codex calls one of six closed MCP tools. The bundled coordinator authenticates a source-owned PyKrita extension over an ephemeral `127.0.0.1` endpoint. Inspection, paint-layer transactions, document projection, save, reload, and readback execute on Krita 5.3.3's application thread through PyKrita 5.3.3. A bridge-owned process-local profile gives the native process a distinct home, resource database, Python-plugin directory, configuration, and hard-coded Krita single-instance key without changing the user's running Krita session. Every mutation is guarded by the independently observed document revision, an exact `.kra` checkpoint, native save readback, and an immutable receipt. Bridge Runtime is build and certification authority only; it is absent at runtime.
