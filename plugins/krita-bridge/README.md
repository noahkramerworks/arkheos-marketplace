# Krita Bridge

Free, source-owned Krita 5.3.3 bridge infrastructure for Codex. It exposes six closed semantic tools for status, setup, bounded document inspection, revision-guarded paint-layer edits, PNG export, and exact receipt rollback through PyKrita 5.3.3.

Install with `codex plugin install krita-bridge@arkheos` after adding the ArkheOS marketplace. The same release is available as `krita-bridge@personal` for development. Read `design/plugin.md` for the complete accepted authority and lifecycle contract.
