# QGIS Bridge

Use the narrowest focused Skill. Read [architecture](../../references/architecture.md), [actions](../../references/actions.md), and [security and state](../../references/security-and-state.md). Route installation, enrollment, launch, or owned shutdown to `$setup`; read-only project state to `$inspect`; closed layer/layout changes to `$edit`; PNG/PDF layout output to `$export`; a known receipt to `$rollback`; and reconstruction or drift to `$recover`. Never substitute UI automation, Python, Processing, SQL, raw commands, generic properties, or unrestricted paths.
