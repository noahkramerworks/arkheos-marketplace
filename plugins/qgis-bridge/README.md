# QGIS Bridge

Free, Bridge Runtime-certified control of QGIS 4.2.0 through the documented PyQGIS API.

Use `qgis-bridge@personal` or `qgis-bridge@arkheos`. The bridge exposes six closed tools for status, setup, project inspection, layer/layout transactions, PNG/PDF layout export, and exact receipt rollback. It never accepts Python, SQL, processing expressions, provider strings, shell commands, raw payloads, or unrestricted paths. Read `design/plugin.md` for the complete package and lifecycle contract.
